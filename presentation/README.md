# Presentation sections

The project is organized into three presentation sections. The executable
scripts remain in their original locations because they use root-relative
paths and imports.

1. [01-model](01-model/README.md) - detector, depth, localization, risk, and
   runtime pipeline.
2. [02-carla-data](02-carla-data/README.md) - CARLA collection, annotations,
   conversion, and sequence-disjoint splits.
3. [03-fine-tuning](03-fine-tuning/README.md) - YOLO training, evaluation,
   checkpoints, and reported results.
